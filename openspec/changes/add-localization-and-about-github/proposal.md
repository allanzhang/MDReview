## Why

MDReview 当前所有自定义界面文案均为英文硬编码，中文用户体验不完整；About 页面也缺少项目归属和进入源码主页的入口。需要补齐中英文能力，并让用户可以按系统语言或手动指定语言使用应用。

## What Changes

- 增加语言偏好，提供三个互斥选项：跟随系统、中文、English。
- 默认使用“跟随系统”。系统首选语言以 `zh` 开头时显示简体中文，其他系统语言显示英文。
- 选择“跟随系统”“中文”或“English”后立即更新应用界面，不重启应用；所选模式持久化到本机并在后续启动中保持。
- 语言偏好入口放在 View 菜单的 Language 子菜单中，与现有 Appearance 子菜单并列。
- 本地化覆盖应用自定义的用户可见文案，包括主窗口、工具栏、菜单、上下文菜单、工具提示、About、更新提示、错误和确认弹窗。
- 用户打开的 Markdown 文档内容不翻译。
- 系统语言变化时，仅在“跟随系统”模式下立即重新解析并刷新应用界面，不重启应用。
- About 页面增加版权文案 `© 2026 MDReview`。
- About 页面增加 GitHub 按钮，点击后用系统默认浏览器打开 `https://github.com/allanzhang/MDReview`。
- GitHub 按钮文案在中文界面显示“GitHub 项目主页”，在英文界面显示“GitHub Project”。

## Capabilities

### New Capabilities

- `app-localization`: 管理语言偏好、系统语言解析、即时切换、持久化以及全部应用自定义 UI 文案的中英文映射。
- `about-github`: 管理 About 页面版权展示、GitHub 项目入口及其本地化行为。

### Modified Capabilities

无。

## Impact

- 新增语言偏好模型和本地化字符串资源。
- 修改应用菜单、主窗口、工具栏、上下文菜单、About、更新流程和弹窗中的硬编码文案。
- 修改 `DocState` 或等价应用级状态以分别发布所选语言模式和实际显示语言，持久化模式，并在手动选择或系统语言变化时驱动界面即时刷新。
- 新增本地化与 About 链接的行为测试；现有渲染器测试不受影响。
- 不新增网络请求、账号能力或文档内容翻译；GitHub 按钮只调用系统浏览器打开固定项目地址。
