# MDReview 测试清单

自动化部分由 `node Tests/run.js` 一次跑完，全部通过才算机器测试通过。人工部分需要在真实窗口里逐项核实。

## 机器测试

共 13 条状态断言 + 3 条源码契约，定义在 `Tests/DocStateTests.swift` 与 `Tests/run.js` 的 `runViewStructureContractTests`。

### 文档打开

| 条目 | 预期 |
|---|---|
| 打开 .md / .markdown | rawText 与 url 更新，进入最近列表并置顶，lastUrl 记录 |
| 打开非 markdown 文件 | 忽略，状态不变 |
| 快速连续打开两个文件 | 后一个胜出，先发起的读盘结果不覆盖后一个 |
| lastUrl 指向的文件已不存在 | lastDocumentURL 返回 nil，不报错 |
| 外部编辑器保存当前文件 | hasPendingFileUpdate 置真 |
| 原子替换方式保存 | 第一次保存后监听仍有效，后续改动继续标记 |
| 文件被删除 | 停止标记更新，不持续报错 |

### 最近列表

| 条目 | 预期 |
|---|---|
| 连续打开 A 再打开 B | 顺序为 [B, A]，lastUrl 为 B |
| 重复打开同一文档 | 置顶且不产生重复条目 |
| 清空最近列表 | recent 为空，lastUrl 清除，当前文档保持打开 |
| 清空后再次打开当前唯一文档 | recent 与 lastUrl 都恢复 |
| 移除单项 | 只移除该项，其余顺序不变 |
| 打开超过 30 篇 | 最旧一条被淘汰 |
| 加载时路径已不存在 | 该路径不进 recent |

### 源码契约

这三条扫源码文本，防止已修复的 bug 被改回去。

| 条目 | 守住的 bug |
|---|---|
| RecentView 的 contextMenu 位于 Button label 内 | 右键最近列表卡死主线程 |
| onHover 修饰在控件内部（RecentView、OutlineView、FontSizeButton） | 鼠标移动时高亮卡住不动 |
| clearRecent() 清除 lastUrlKey | 清空历史后重启仍打开最后一篇 |

### 其他套件

语言、版本号、更新完整性、关于页链接、主菜单本地化、文件拖放解析、代码折叠、渲染黄金样本、CommonMark 一致性、本地化键完整性。这些不涉及本次交互改动，随 `node Tests/run.js` 一起执行。

## 人工测试

### 文档打开

| 操作 | 预期 |
|---|---|
| 拖一个 .md 文件进窗口 | 正常打开并出现在最近列表 |
| 打开文档后退出再启动 | 自动恢复该文档 |
| Finder 里双击 .md 文件启动应用 | 打开被双击的那篇，不是上次的文档 |
| 外部改动文件后点刷新 | 内容更新 |
| 把当前文件移走后再点刷新 | 红色更新标记保留 |

### 侧栏

| 操作 | 预期 |
|---|---|
| 切换大纲 / 最近 | 对应列表跟着切换 |
| 折叠再展开有子标题的节点 | 子标题隐藏后恢复 |
| 点击大纲某一行 | 正文滚动到对应标题 |
| 隐藏侧栏再显示 | 正常来回切换 |
| 隐藏侧栏后退出再启动 | 侧栏保持隐藏 |

### 阅读

| 操作 | 预期 |
|---|---|
| 切到源码再切回渲染 | 两次切换都生效 |
| 切回渲染后 | 滚动位置和大纲高亮停在离开前的位置 |
| 搜索框快速连续输入 | 结果只刷新一次，不逐字卡顿 |
| 字号调到最小和最大 | 到边界后不再变化，中间步进均匀 |
| 外观按钮点两次 | 跟随系统切到手动，再点回到跟随系统 |
| 手动外观下退出重启 | 恢复为跟随系统 |

### 菜单与标题栏

| 操作 | 预期 |
|---|---|
| 逐个点文件和视图菜单项 | 每项触发对应功能 |
| 导出 HTML 和 PDF | 生成文件并弹出成功提示 |
| 用外部编辑器打开 | 有 Cursor 或 VSCode 时用它们，否则用系统默认应用 |
| 鼠标在标题栏和字号按钮间来回移动 | 高亮随鼠标离开而消失，不卡住 |
