# 交互路径清单

每行一条用户可触发的路径。覆盖状态只有三个值：`已覆盖`（有断言）、`待补`（纯状态可断言但尚无测试）、`需人工`（只能在真实窗口验证）。

待补项在用户确认前不写测试。

## 文档生命周期

| 触发入口 | 预期结果 | 覆盖状态 |
|---|---|---|
| 打开 .md / .markdown 文件 | rawText 与 url 更新，进入 recent 并置顶，lastUrl 记录 | 已覆盖 |
| 打开非 markdown 文件 | 忽略，状态不变 | 已覆盖 |
| 拖入文件到窗口 | 与打开相同 | 需人工 |
| 重启且 lastUrl 指向的文件仍存在 | 自动恢复该文档 | 需人工（restoreLastDocument 在视图层且含启动时序） |
| 重启且 lastUrl 指向的文件已不存在 | 停留空白，不报错 | 已覆盖（lastDocumentURL 返回 nil） |
| Finder 双击打开（didOpenViaSystem） | 不触发自动恢复，避免与系统打开竞态 | 需人工（依赖 AppKit 启动时序） |
| 外部编辑器保存当前文件 | hasPendingFileUpdate 置真，防抖合并多次写入 | 已覆盖 |
| 文件被删除或重命名 | 停止监听，不持续报错 | 已覆盖 |
| 手动刷新且内容有变化 | rawText 更新并重渲染 | 需人工（refreshDocument 在视图层） |
| 手动刷新但读盘失败 | 保留更新红点 | 需人工 |
| 打开大文件期间又打开另一个 | 先发起的读盘结果被丢弃，不覆盖后一个 | 已覆盖 |

## 最近列表

| 触发入口 | 预期结果 | 覆盖状态 |
|---|---|---|
| 连续打开 A 再打开 B | recent 顺序 [B, A]，lastUrl 为 B | 已覆盖 |
| 重复打开已在列表中的文档 | 置顶且不产生重复条目 | 已覆盖 |
| 清空最近列表 | recent 为空，lastUrl 清除，当前文档保持打开 | 已覆盖 |
| 清空后再次打开当前唯一文档 | recent 与 lastUrl 都恢复 | 已覆盖 |
| 右键移除单项 | 只移除该项，其余顺序不变 | 已覆盖 |
| 打开超过 30 篇 | 最旧一条被淘汰 | 已覆盖 |
| 重启加载时路径已不存在 | 该路径不进 recent | 已覆盖 |

## 侧栏

| 触发入口 | 预期结果 | 覆盖状态 |
|---|---|---|
| 切换大纲 / 最近 | showOutline 翻转，对应视图显示 | 需人工 |
| 折叠 / 展开有子标题的节点 | 子节点隐藏或显示，状态记忆 | 需人工 |
| 点击大纲行 | 正文滚动到对应标题 | 需人工 |
| 切换侧栏显隐 | columnVisibility 在 .all 与 .detailOnly 间切换 | 需人工（依赖 AppKit 应用上下文，无窗口时崩溃） |
| 重启后侧栏显隐 | 恢复上次状态 | 需人工（同上） |

## 阅读

| 触发入口 | 预期结果 | 覆盖状态 |
|---|---|---|
| 切换源码 / 渲染 | showSource 翻转，离开渲染前抓取滚动与进度快照 | 需人工 |
| 切换后回到渲染 | 恢复离开时的滚动位置与大纲高亮 | 需人工 |
| 搜索输入 | 停顿 250ms 后执行一次，连续输入不重复触发 | 需人工 |
| 字号缩放 | 范围限制在 0.8 到 1.5，步进 0.15 | 需人工（逻辑内联在视图按钮里） |
| 外观切换 | system 与手动覆盖之间循环，不持久化 | 需人工（读取 NSApp 外观，无应用上下文时崩溃） |

## 菜单与标题栏

| 触发入口 | 预期结果 | 覆盖状态 |
|---|---|---|
| 菜单项点击 | 经 NotificationCenter 转发到对应处理 | 需人工 |
| 导出 HTML / PDF | 生成文件并提示成功 | 需人工 |
| 在外部编辑器打开 | 优先 Cursor / VSCode，否则系统默认应用 | 需人工（依赖本机安装的应用，结果不稳定） |
| 右键最近列表项 | 弹出菜单且不触发打开文档 | 已覆盖（源码契约） |
| 鼠标移出字号按钮 / 大纲行 / 最近行 | hover 高亮消失，不残留 | 已覆盖（源码契约） |
